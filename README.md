# Paper Cards · 论文精读卡片库

把顶会论文做成**带评分的精读卡片**——每篇论文一张卡片，包含四维评分、创新点、方法框架、可借鉴点和缺点。

以卡片为单位阅读，而不是以 PDF 为单位。

**在线浏览 →** https://zms618.github.io/paper-cards/

## 每张卡片有什么

```json
{
  "title": "论文标题",
  "scores": {
    "novelty": 6.5,      // 问题层面的新颖性，不是"有没有新模块"
    "depth": 7.0,        // 数学与机制设计的严密程度
    "evidence": 5.0,     // 基线强度、消融完整性、方差与显著性
    "relevance": 7.0,    // 与研究者主线的相关性
    "overall": 6.5       // 0.25/0.25/0.20/0.30 加权
  },
  "one_line": "一句话概括核心判断",
  "innovations": ["具体到机制，不用'提出新颖框架'这类空话"],
  "method_framework": "方法脉络",
  "experiment_framework": "数据集 / 基线 / 指标",
  "takeaways": ["可迁移到自身研究的做法"],
  "weaknesses": ["必须指向正文中的具体缺陷"],
  "confidence": "high | medium | low"
}
```

## 评分标准

评分遵循一份**反通胀量规**——刻意不宽容：

- 随机一篇顶会论文 ≈ **5.5**
- 扎实增量工作 ≈ **6.5**
- **7 分以上必须稀有**（实际占 2.5%）
- 8 分以上极罕见（本库当前仅 1 张）

全库实测：均值 **6.07**、中位数 **6.1**。这不是"什么都给高分"的收藏夹。

四条硬规则：

1. **禁止词汇触发式给分**——标题里出现 `robust` / `generalization` / `hallucination` 不等于相关工作。
2. **警惕术语跨领域歧义**——3DGS 的 "consistency" 不是可信 AI 的鲁棒性。
3. **报多个种子却只给均值、无标准差 → evidence 上限 6**。
4. **平庸的无关论文 relevance 就是 3-4**，不因整体质量高而抬高。

## 站点结构

- **按主题**：可靠性·泛化·不确定性 / 医学影像·病理 / 多模态·视觉语言 / 大模型·推理 / 生成模型 / 强化学习·具身 / 高效计算 / 视觉感知 / 表征学习
- **按会议**：6 个顶会独立入口，可按任意维度排序、按会议筛选
- **搜索**：全库标题与一句话评价全文检索
- **双语**：中文 / English 界面切换

## 技术实现

零依赖静态站，纯 Python 标准库生成：

```
paper-site/
├── build_site.py     # 生成器：卡片 JSON → 静态 HTML
├── data/             # 卡片数据（按会议分目录）
└── site/             # 构建产物（42,700 个页面）
```

```bash
python build_site.py
# OK cards=21332 confs=6 topics=10 (zh+en)
```

生成 21,350 个页面约需 3 分钟。产物分中文（`.html`）与英文（`.en.html`）两套，通过 `localStorage` 记住语言偏好。

## 数据来源

卡片由 LLM 审稿代理按统一量规逐篇阅读论文正文后生成，仅依据正文判断，正文未提及的方面不作臆断。每张卡片的 `confidence` 字段标注了正文信息的充分程度（正文截断、缺消融表等情况会降级）。

如果你也在做论文精读，这套「卡片 + 量规」的思路可以直接借鉴——**关键不在于写多少字，而在于敢不敢给低分**。
